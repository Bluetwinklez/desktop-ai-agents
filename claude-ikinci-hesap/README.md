# Claude 2. hesap baslatici

Klon uygulama yok: ayni Claude Desktop, ayri veri klasoruyle ikinci kez acilir.

- Mac: `mac-claude-hesap2.command` dosyasina cift tikla (once `chmod +x`).
- Windows: `windows-claude-hesap2.bat` dosyasina cift tikla. Kisayol olusturup masaustune koyabilirsin.
- Ilk acilista 2. hesapla giris yap. Normal Claude simgesi 1. hesapta kalir.
- Veri klasoru: `~/claude-hesap2` (degistirmek icin `CLAUDE_HESAP2_DIR`).

Calismazsa: Claude tek-ornek kilidi kullaniyor olabilir (ikinci pencere acilmaz).
Claude Code'u terminalde kullaniyorsan: `CLAUDE_CONFIG_DIR=~/.claude-hesap2 claude`
